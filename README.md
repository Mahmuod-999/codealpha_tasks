📊 Unemployment Rate Analysis Project
📌 Overview

- This project analyzes unemployment rate data over time to understand trends, regional differences, and the impact of major economic events such as the Covid-19 pandemic.
- The goal is to extract meaningful insights that can support economic and policy decision-making.

🎯 Objectives
- Analyze unemployment trends over time
- Investigate the impact of Covid-19 on unemployment rates
- Compare unemployment across different regions
- Identify possible seasonal patterns
- Extract actionable insights from the data

🗂️ Dataset Description
- The dataset contains:
- Date: Time of observation
- Estimated Unemployment Rate (%): Percentage of unemployed individuals
 - Region: Geographic area of data collection

🛠️ Tools & Libraries
- Python
- Pandas
- Matplotlib
- Seaborn

📊 Project Workflow
1. Data Cleaning
- Handled missing values
- Converted date column to datetime format
- Sorted data chronologically
- Ensured correct data types

2. Exploratory Data Analysis (EDA)
- Summary statistics
- Distribution of unemployment rates
- Initial understanding of data behavior

3. Trend Analysis
- Visualized unemployment rate over time
- Identified fluctuations and patterns

4. Covid-19 Impact Analysis
- Compared unemployment before, during, and after Covid-19
- Identified significant spike during the pandemic

5. Regional Analysis
- Compared unemployment rates across different regions
- Identified regional disparities

6. Seasonal Analysis
- Checked for monthly patterns
- Observed mild seasonal variations

💡 Key Insights
- Unemployment rates fluctuate significantly over time
- Covid-19 caused a major spike in unemployment levels
- Recovery after Covid-19 was gradual
- Regional differences strongly affect unemployment rates
- Seasonal patterns exist but are less impactful than economic events
